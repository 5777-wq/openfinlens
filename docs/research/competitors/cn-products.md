# 中文行情产品拆解：同花顺 / 东方财富 / 雪球

## 0. 一句话定位

- 同花顺：给高频交易者的行情、交易、选股全能工作台，图表和盘口最深，但付费墙与App导流也最密。
- 东方财富：以股吧流量和券商、基金交易闭环为底座的一站式财经门户，数据全、入口多、广告也最多。
- 雪球：以UGC社区和基金、私募配置为核心的长期投资平台，行情是社区与交易的配套设施，不是主角。

> 研究时间：2026-10-21 10:46-11:20（UTC+8）。对象：同花顺（10jqka.com.cn / App，重点）、东方财富、雪球。方法：curl + Chrome UA 抓 HTML；Edge --headless=new --dump-dom 取渲染DOM；公开 JSON API；App Store 公开页与公开评价RSS；未登录、未安装App、未真机操作。

## 9. 可感知的摩擦点

### 9.1 同花顺

1. 付费墙贴脸[实测]：五档标题旁直接放看十档，短线精灵旁放Level-2短线神器；用户只是来看五档，也会被Level-2促销打断。
2. App导流打断[实测]：移动站5秒倒计时加立即下载；个股页中部打开同花顺和专业的股民一起炒股；新闻列表底部打开同花顺查看全部公司新闻。
3. 搜索文案与能力不一致[实测]：placeholder写代码/拼音首字母，JS却只把输入拼进hs_加code；输入gzmt得到200的通用模板页，没有未找到提示。
4. 页面跳转层级深[实测]：个股页6个内容tab全是不同URL；看盘口、资金、资料、资讯要来回跳，移动端才收进tab。
5. 推送/电话骚扰[公开-用户评价]：App Store评价有每天打电话骚扰，既然非要逼着人评论，那就只能给你个差评；[推断] 增长团队把推送/回访/评分弹窗用得很重。
6. 功能臃肿/反馈困难[公开-用户评价]：app越做越花里胡哨，反馈问题连反馈的地方都没有；[实测] PC图表有11个周期、20+画线工具、13+指标，对新手是过载。
7. 游客行情延迟[实测]：移动行情中心明确写游客行情将延迟十五分钟，请注册并登录领取level2实时行情；[未验证] A股是否同样延迟，但文案会让用户觉得不登录就只能看旧数据。

### 9.2 东方财富

1. 广告多[实测]：PC首页HTML有11个iframe、128处广告相关标记（含same.eastmoney.com、adbox等字符串，未逐条确认是否全部展示）；个股页8个iframe、25处标记。[公开-用户评价]：App Store评价底部按钮太多，开屏广告太多、各种广告乱七八糟、软件启动有开屏广告，垃圾软件、就是广告太多了！

## 10. 对我们的可借鉴 / 不要学

### 可借鉴（5条，具体可执行）

1. 首屏报价加图加一条周期横滑。照同花顺PC个股页：首屏只放报价（现价/涨跌/高开低换额/市值/量比/PE）加图加周期条；周期顺序固定为分时/日K/周K/月K/季K/年K/120分/60分/30分/15分/1分，默认日K；指标收进一个指标按钮，不要一上来铺13个指标。验收：首屏可交互元素不超过15个；从首页到第一张日K不超过3次点击。
2. 五档加明细同屏，220-260px高度内完成。照同花顺移动个股页：图下方左侧五档（卖5到买5，价格加手数），右侧或下方明细tab（时间加价格加手数）；点tab切换，不跳页；五档不做付费遮罩。验收：窄屏375px下五档10行加明细10行不需要横向滚动；首屏能看到至少5档。
3. 列头即排序加板块chips加明确分页。照同花顺q页面：默认涨跌幅降序；列头点击切asc/desc；板块chips全部/沪/深/京/创业板/科创板；底部1/N加下一页加尾页。不做无限滚动加不知道总共多少条的黑盒。验收：任意列头点击1次即排序；分页信息始终可见；切换板块后保留排序字段。
4. 搜索框给3个预设问题加真正的代码/名称/拼音联想。照同花顺首页AIME chips（今日量能如何评/成交额历史对比/今日放量股）加东财suggest（Code/Name/PinYin/QuoteID）。空搜索框时给3个可点chips；输入时下拉分组股票/板块/资讯；代码、名称、拼音首字母三路都要通。验收：输入600519、贵州茅台、gzmt都能在1次请求内返回同一只股票；无结果时显示未找到，试试代码/名称，而不是空白页。
5. 自选等于分组加多股同列加批量设置。照东财自选页：新建组合/指标设置/批量设置；视图我的自选/资金流向/财务数据/多股同列/盈亏一览；添加框支持代码、名称、简拼或关键字。同花顺的动态分组可以作为二期：按策略每天刷新一个分组。验收：同一份自选能在1次点击内切换看行情/看资金/看财务/多股同列；批量设置能一次改多只股票的列。

### 不要学（5条，具体可执行）

1. 不要在核心行情路径塞广告。东财PC首页11个iframe、128处广告标记，个股页8个iframe；雪球用户评价信息流广告一占就是半屏。我们的规则：首页/个股页/五档/搜索首屏0广告；广告只能出现在资讯流、且默认折叠或可关闭；开屏广告不做。
2. 不要把20+模块堆进个股页。东财个股页20+模块、12个F10加12个特色数据入口；用户评价同花顺越做越花里胡哨。我们的规则：个股页首屏只放报价加图加五档/明细加3个tab（资讯/资金/财务）；F10、研报、股吧、排行全部二级页；每加一个模块必须删一个或收进更多。
3. 不要用5秒倒计时或强制下载拦截Web。同花顺移动站5s后自动跳转加立即下载，个股页中部还有打开同花顺横幅。我们的规则：Web首屏不拦截；App下载条只做底部细条、可关闭、不遮内容；核心K线/五档在Web上必须完整可用。
4. 不要在五档/盘口里放看十档付费teaser。同花顺把看十档直接放在五档行情标题旁，把Level-2徽标放在短线精灵旁；用户看免费数据时被反复提示付费。我们的规则：五档区域0付费按钮；Level-2/十档放在独立高级行情入口，进入前明确说明差异与价格；免费五档不缩水、不延迟（除非交易所要求）。
5. 不要承诺未实现的搜索能力。同花顺H5 placeholder写代码/拼音首字母，JS却只拼hs_加code；输入gzmt返回200的通用模板页。我们的规则：搜索框文案必须与能力一致；上线前用600519、贵州茅台、gzmt、错别字、无结果五组用例验收；无结果要有明确空状态和下一步建议。
