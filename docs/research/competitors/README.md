# 竞品操作逻辑调研 · 汇总与结论（2026-10-21）

> 目录四份材料：`tradingview.md`（TradingView）、`cn-products.md`（同花顺/东财/雪球）、`global-web.md`（Finviz/Yahoo/Investing/Koyfin 等）、本汇总。另参照仓库既有 `docs/WORLDMONITOR-ANALYSIS.md`（技术层逆向）。
> 方法：真实抓取（HTML/JSON/帮助页/定价页/反编译 JS），未登录、未真机。证据等级在各分报告逐条标注［实测/公开/推断/未验证］。

## 一、七个产品的一句话定位（先看这个）

| 产品 | 定位 | 免费墙位置 |
|---|---|---|
| **TradingView** | 全球散户到半专业的**图表工作台**，卖工作台不卖数据 | 每图表 2 个指标、分钟历史 180 天、1 个保存布局 |
| **Finviz** | 用一张高密度表 + 一张热力图把美股全市场压进一屏的**密度标杆** | 延迟数据、导出、高级筛选、图表（点 Charts 直接弹 Elite 框） |
| **Yahoo Finance** | 大众**流量入口**，"什么都能查到"而非"一屏看尽" | 实时数据、组合工具、深度研究 |
| **Investing.com** | 全球资产类别最全的**行情门户** | Fair Value/健康度/目标价锁进 Pro+ |
| **同花顺** | 高频交易者的**全能工作台**，图表盘口最深，导流和付费层也最密 | Level-2/十档/主力资金/选股器五层阶梯 |
| **东方财富** | 以股吧流量 + 券商基金交易闭环为底座的**一站式门户** | Level-2 + 交易转化 |
| **雪球** | UGC 社区 + 基金私募配置的**长期投资平台**，行情只是配套设施 | 变现在财富管理，不在行情本身 |

**我们的定位**（从 README 与代码反推）：零账号、零 key、打开即用的**免费全球情报终端**——热力图/事件地图/披露数据是主菜，行情图表是底座。**在"密度"上对标 Finviz，在"无门槛"上反打 TradingView，在"干净"上反打中文门户。**

## 二、他们最强的三件事（每家一件）

1. **TradingView 的图表深度**：秒级到月 + Renko/Kagi 等非时间图 + Pine 脚本生态 + 跨平台。这是 15 年积累的护城河，**不追**。
2. **Finviz 的"筛选/视图/排序三态正交且全部进 URL"**：`?v=121&f=sec_technology,cap_large&o=-marketcap` 可分享可回退，82 个筛选字段 15 个视图复用，SSR 无 JS 也能读数据。**这是我们差距最大、投入产出比也最高的一课。**
3. **同花顺的个股页信息编排**：首屏报价（现价/涨跌/换手/量比/PE）+ 图 + 周期条，指标收进一个按钮不铺开；五档+明细 220px 内同屏。**密度与克制的平衡值得照抄。**

## 三、他们共同的坑（我们的差异化机会）

| 坑 | 谁最严重 | 我们现状 |
|---|---|---|
| **广告插在核心路径** | 东财首页 11 个 iframe、128 处广告位；Finviz 筛选器和结果之间插 970×315 广告；雪球信息流广告占半屏 | 我们零广告（无账号无变现，天然干净）——**这是最该大声说的差异** |
| **付费墙锁在数据单元格** | Investing 5 列变 Upgrade to Pro+；Seeking Alpha 每行挂 Locked；同花顺五档旁边挂"看十档"付费 teaser | 我们免费全开——指标数量、分钟历史、布局均不设墙 |
| **导航臃肿** | Finviz/Investing 一级导航 18–19 项 | 我们 11 个 tab，已接近上限，**再加功能必须合并而不是加 tab** |
| **App 导流拦截 Web** | 同花顺 H5 5 秒倒计时跳转 + "打开同花顺"横幅 | 我们 PWA 安装即用，无拦截 |
| **分页黑盒** | Finviz 5607 股 / 20 行每页 = 281 页 | 我们全市场热力图一屏无分页（treemap 本身就是答案） |
| **反爬挡住正常分享** | Finviz headless 被 Cloudflare 拦、MarketWatch 401、Investing 403 | 我们静态部署在 GitHub Pages，链接永远可开 |

## 四、我们已有的、他们没有的（不要妄自菲薄）

1. **热力图即筛选器**：图例点击隐藏涨跌幅区间——Finviz 的热力图做不到这一点，它的图例是纯图例。
2. **指数不进热力图**：Treemap 只画个股，指数在上证宽度条和跑马条，不占面积——Finviz 的 S&P500 树里指数和个股混排（Top10 占 40.8% 面积的失真问题，他们用 Equal Size 开关打补丁）。
3. **事件→K线落位**：全球事件按日期画进 K 线，点事件看那天价格发生了什么——七家竞品没有一家把新闻事件直接钉在 K 线上（TV 有 earnings 标记但只限财报）。
4. **终端式快捷键 + hash 深链**：`1-9` 切 tab、`/` 聚焦搜索、Backspace 返回、`#symbol=xx` 分享（连基金对比的完整参数 f/start/end/g/n/a/log 都进 hash）。**这在密度型产品里是 Finviz 级别的设计**，我们已经有了。
5. **数据诚实原则**：拿不到就标注口径（"价格收益（未含分红）"）、降级链 + 角标、空态不白屏——七家里没有一家对"数据口径"这么较真（TV 的 dividend-adjusted 是付费功能才有区分度）。

## 五、按投入产出排序的行动清单

1. **周期下拉加"更多周期"**（半天）：分时/日K 的分段按钮保留，加一个"5/15/30/60 分钟"入口——数据源现成（腾讯 mkline m5/m15/m30/m60，800 根上限），零新增依赖。对标：TV 的周期选择器收纳逻辑。
2. **个股页首屏照同花顺三段式重排**（1 天）：报价区（现价/涨跌/换手/量比）+ 图 + 周期条，指标收进一个按钮。验收：首屏可交互元素 ≤15、首页到第一张 K 线 ≤3 次点击。
3. **筛选/排序进 URL**（1–2 天）：市场焦点和涨跌幅榜的排序字段、板块 chips 进 hash（`#tab=cn&sort=pct&desc=1`），分享出去即所见。对标：Finviz 三态正交。
4. **搜索联想补拼音首字母**（1 天）：`gzmt` → 贵州茅台。东财 suggest 接口已支持 PinYin（Code/Name/PinYin/QuoteID 三路），我们已在用东财 suggest——**大概率是解析层没接全，查一下就是半天的事**。
5. **空状态给三个预设 chips**（2 小时）：搜索框聚焦且为空时显示"今日量能/成交额对比/今日放量"这类可点建议。对标：同花顺 AIME chips。

## 六、不要做的事

1. 不追图表深度（TV 的护城河，追不上也没必要——我们用 lightweight-charts 的克制是对的）。
2. 不做社区（雪球/TV 的路线都要账号+审核+垃圾内容治理，违背零账号定位）。
3. 不加第 12 个 tab——再有新功能进"设置"或合并进既有 tab。
4. 不学 Investing/Yahoo 的"门户化"——宽导航是流量逻辑，不是工具逻辑。
5. 不学 Finviz 的 281 页分页——treemap 就是我们对"全市场"的回答。
