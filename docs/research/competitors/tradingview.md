## 一句话定位

TradingView 是给全球散户到半专业交易者用的**超级图表工作台**：把深度 K 线、画图/指标、自选与提醒、筛选器、社区观点和下单入口，围绕一张可保存、可分享的 Superchart 组织起来。**它卖的不是行情数据，是"图表工作台"本身**——数据是燃料，图表和社区是产品。

## 1. 付费墙的精确切割（定价页实测，最硬的证据）

```
Charts per tab:          1   2   4   8   16        ← Basic/Essential/Plus/Premium/Ultimate
Saved chart layouts:     1   5   10  (custom)      ← 同上
Indicators per chart:    2   5   10  ...           ← 免费墙第一刀切在这
Historical data (min):   180d 365d All All All      ← 免费只有 180 天分钟历史
Historical annual fin.:  7y  20y 20y 20y 20y       ← 年度财务图表免费 7 年
Simultaneous connections:2   10  20  50  200
价格提醒:                 少量 有限 100 ...          ← Plus 起 100 price alerts
不过期提醒:               ✗   ✗   ✗   ✓   ✓        ← Premium 才有
Orderflow（订单流）:      ✗   ✗   部分 ✓   ✓        ← 专业档
```

**对我们的含义**：TradingView 免费档"每图表 2 个指标"这条限制，正是我们"零 key 免费用全部指标"最直接的差异化卖点。我们 README 里的指标（RSI/MACD/KDJ/BOLL）免费全开，这是真实优势，不是营销话术。

## 3. 对我们的可借鉴 / 不要学

### 可借鉴
1. **"图表分享"是传播引擎**：TV 每张图可生成公开链接（含布局和画线）。我们已有 `#symbol=xx` hash 分享，但只到"标的"粒度，不到"图表状态"（周期/指标/画线）粒度。如果基金对比的深链（已有 f/start/end/g/n/a/log 参数）推广到全部图表，分享能力上一个台阶。
2. **周期选择器的一屏收纳**：TV 把秒到月+非时间图全部收进一个下拉，我们目前分时/K线是分段按钮。若加"更多周期"下拉（1/5/15/30/60 分钟），操作路径不变、能力翻倍——且腾讯 `mkline` 本来就支持 m5/m15/m30/m60（800 根上限，见调研 README §2.1）。
3. **免费墙切在哪是产品哲学**：TV 切在"指标数量"（用了就想要更多）而不是"能不能看图"（看不了就走了）。我们零门槛全开，反而要在**别处**建立价值感（数据可靠性角标、事件关联、披露数据深度），不要让用户觉得"免费=没东西可付费升级"。这里我们刻意不同：不做账号体系，价值感来自"打开就有、离线能看"。

### 不要学
1. **不要学它的 SPA 壳**：`/chart/` 抓下来是 75KB 空壳，一切靠 JS 注水。我们是静态优先（noscript 有骨架、SSR 数据可见），这是我们的加载速度优势，别丢。
2. **不要学"免费 180 天分钟历史"**：我们数据源（腾讯/东财/同花顺）的分钟历史天然比这深（同花顺 5min 约 1 年），零成本全给。
3. **不要学社区/社交**：TV 的 Idea 板块是它的护城河但也是重资产（审核、垃圾内容、账号体系）。我们的"事件→资产"路线与社区观点路线是两条路，不要羡慕别人的护城河就去挖自己的墙角。
